# Web Personal - estimprog-del

Página web personal tipo portafolio/directorio que centraliza todas las aplicaciones del desarrollador **estimprog-del**, con enlaces directos a cada una.

## URL objetivo

https://estimprog-del.github.io/web-personal/

## Estructura

```
web-personal/
├── index.html      ← Página principal con tarjetas de cada app
├── styles.css      ← Estilos (responsive, móvil primero)
├── app.js          ← Interactividad simple
├── assets/
│   ├── icons/      ← Iconos/capturas de cada app
│   └── screenshots/
└── README.md
```
