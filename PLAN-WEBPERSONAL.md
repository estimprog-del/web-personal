\## Estructura sugerida (carpeta raíz del nuevo repo)

web-personal/

├── index.html          ← Página principal con tarjetas de cada app

├── styles.css          ← Estilos (responsive, móvil primero)

├── app.js              ← Opcional, interactividad simple

├── assets/

│   ├── icons/          ← Iconos/capturas de cada app

│   └── screenshots/

└── README.md



\## Tecnología recomendada

\- HTML5 + CSS3 + JavaScript vanilla (sin frameworks)

\- GitHub Pages para alojamiento gratuito

\- Diseño mobile-first, tarjetas grandes, botones claros
